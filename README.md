# Student Finance Tracker

This is a personal project I built to help students (like me!) keep an eye on their money. It's a simple, responsive web app that tracks where your money goes and helps you stay within your budget.

## What it can do
- **Real-time Dashboard**: Instantly see your total balance and top spending categories.
- **Smart Validation**: The app makes sure your data is clean (e.g., descriptions need at least one letter).
- **Responsive Design**: It works perfectly on both your phone and your computer.
- **Privacy First**: All your data is saved locally on your browser—no backend required.
- **Charts**: Includes simple charts to visualize your last 7 days of spending.

## Project Structure
Here's a quick look at how the files are organized:
- `index.html` & `pages/`: The main views of the app.
- `styles/`: All the CSS files for themes, layouts, and components.
- `scripts/`: The logic behind the dashboard, forms, and data storage.
- `tests.html`: A dedicated page to run validation tests.
- `seed.json`: Some sample data to get you started.

## Design & Sketches
Before I started coding, I hand-drew some sketches to plan out the layout and user flow. You can find these  in the `sketchs/` folder!

## 🛠️ How to get started
1. **Clone the project**: `git clone https://github.com/Alicia-Keza/Finance-Tracker.git`
2. **Launch**: Just open `index.html` in any browser.
3. **Seed Data**: You can import the `seed.json` file from the Settings page to see some example data.

## 🧪 Testing
If you want to check out the validation logic, just open `tests.html`. It runs a suite of automated tests to ensure everything is working as expected.
